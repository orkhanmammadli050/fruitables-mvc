# Fruitables MVC - Monolithic E-Commerce Application

This is the original monolithic Spring Boot MVC implementation of the Fruitables e-commerce platform. It features server-side rendering with Thymeleaf, full shopping cart logic, order management, dynamic discount calculations, and PostgreSQL database integration.

> ℹ️ **Note:** This project has been fully refactored into a modern, decoupled RESTful API backend architecture. You can check out the updated REST API repository here: [Fruitables API](https://github.com/orkhanmammadli050/fruitables-api).

---

## 🛠️ Tech Stack

* **Java Version:** Java 17
* **Frameworks:** Spring Boot, Spring MVC, Spring Data JPA, Hibernate
* **Template Engine:** Thymeleaf, HTML5, CSS3, JavaScript
* **Security:** Spring Security
* **Database:** PostgreSQL
* **Build Tool:** Apache Maven
